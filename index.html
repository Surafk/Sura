My method

How I troubleshoot a problem

The same five steps, every time. Tap each one.

Listen and reproduce

I ask what the user saw, when it started and what changed, then try to reproduce the problem myself before touching anything.

Narrow it down

Cable, port, device, driver or software? I test one thing at a time, swapping known-good parts, until the cause is clear.

Make the repair

I replace, reconfigure or reinstall the faulty part, keeping the user's data safe with a backup first when needed.

Prove it works

I test the fix under normal use and confirm with the user that the problem is gone, not just hidden.

Write it down

I log the request and what fixed it, and update the hardware inventory, so the next problem is solved faster.
