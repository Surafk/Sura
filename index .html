Networks that just work

I can help with

  • Patch panels and port testing
  • Router and switch setup
  • LAN / WLAN and IP settings

Common problems (tap to open)

One computer has no network

I check the cable and link lights, test the patch cord and port, then check the IP settings.

A new office needs a network

I plan the cable runs, terminate the RJ45 ends, label the ports, set up the switch and router, and test every connection.

The connection is slow or keeps dropping

I look for a bad cable, wrong IP settings or a faulty port, then replace or reconfigure the part at fault.
